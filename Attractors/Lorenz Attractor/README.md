# Lorenz Attractor

This project numerically integrates the Lorenz system using a 
4th-order Runge–Kutta method and visualizes the trajectories.

## Features
- Manual RK4 integrator
- 3D phase-space animation
- Sensitivity to initial conditions in [Chaotic.py]

## Equations
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz
